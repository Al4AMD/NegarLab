# NegarLab (نگارلب)

Bilingual (Persian/English) web-based **image-processing laboratory** for the *Multimedia Systems* course. Load an image, apply algorithms, and see the effect live: pixels, histograms, filters, Fourier views, compression, quality metrics, and ML tools. Every tool pairs an interactive experiment with its theory.

## Prerequisites

- Node.js 22 (`>=22.22.0`) with corepack (provides `pnpm@11.21.0`)
- Python 3.11+ and [uv](https://docs.astral.sh/uv/) 0.12+
- Docker + Compose — optional, for the containerized deployment

## Install

```sh
corepack enable
pnpm install
uv sync --directory apps/api
uv sync --directory tools/golden
uv sync --directory tools/demo_images
```

## Development

```sh
pnpm dev:web   # Vite dev server (web app)      http://localhost:5173
pnpm dev:api   # uvicorn (API, autoreload)      http://localhost:8000
```

The web dev server proxies `/api` to the API. Browser-side tools keep working when the API is offline.

## Checks

```sh
pnpm check      # Biome lint/format, TS typecheck, Vitest, i18n key check
pnpm e2e        # Playwright smoke (builds web, chromium)
pnpm test:api   # backend pytest
uv run --directory apps/api ruff check .
uv run --directory apps/api mypy src
uv run --directory tools/golden pytest -q
uv run --directory tools/demo_images pytest -q
```

Golden vectors define correctness for `packages/ip`: regenerate with `pnpm gen:golden` and commit any intended change. Demo images are synthetic and generated by `pnpm gen:demo`.

## Docker

```sh
cp .env.example .env
docker compose up -d --build
```

Web: `http://localhost:8080` (override with `NEGARLAB_HTTP_PORT`); API behind Caddy at `/api`. Data persists in the `negarlab-data` volume. See [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).
